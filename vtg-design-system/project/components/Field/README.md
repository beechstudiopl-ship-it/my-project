# Field

Pole formularza z etykietą, podpowiedzią i komunikatem błędu powiązanym przez `aria-describedby`.

- Konsument podaje `label` (zawsze widoczna, nie placeholder), opcjonalnie `hint`, `error` (prefiks „Error:” dokłada komponent), `multiline`, `optional`, oraz zwykłe atrybuty inputa (`type`, `name`, `required`…).
- Formularz „Report a fault” na każdej stronie: adres budynku, kontakt, opis usterki (multiline). Krótko — maks. 5 pól.
