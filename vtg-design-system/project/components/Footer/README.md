# Footer

Ciemna stopka z logotypem, krótkim opisem grupy i kolumnami linków — w tym zawsze linki do wszystkich pięciu stron.

- Konsument podaje `logoSrc` (`vtg-lockup-dark.png`), `tagline`, `columns` (`{title, links}`; 3 kolumny), `legal`.
- Pierwsza kolumna na każdej stronie: „Group websites” z pięcioma stronami — drugi, obok `GroupBar`, punkt przejścia między stronami.
