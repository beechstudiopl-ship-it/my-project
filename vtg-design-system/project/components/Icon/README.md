# Icon

Prosty zestaw ikon liniowych (24px, kreska 1.75px, końce kwadratowe) dodany do systemu — źródła marki nie zawierały ikon.

- Konsument podaje `name`, opcjonalnie `size` i `label` (gdy ikona stoi bez tekstu i niesie znaczenie).
- Kolor dziedziczy `currentColor`. `up` w kolorze `up`, `down` w kolorze `down`; pozostałe w `ink-muted` lub `steel-mid`.
