# SiteMark

Znak strony w nawigacji: logotyp grupy, a na stronach specjalistycznych dodatkowo numer (02–05), nazwa i podtytuł specjalizacji.

- Strona grupy (01): tylko `logoSrc`. Strony 02–05: `num`, `name` (sentence case, ≤ 28 znaków), `sub` (pozycjonowanie z dokumentu, np. „Traction & mechanical systems”).
- `logoSrc` = `vtg-lockup-web.webp` z grupy Logos. Wysokość logo 40–48px (`logoHeight`).
- Tylko na ciemnym gruncie — w `NavBar`, który sam jest ciemny.
- Tymczasowe rozwiązanie do czasu potwierdzenia nazw spółek i logotypów: gdy pojawią się finalne znaki, podmień `logoSrc`, nie składaj nowych znaków z typografii.
