# FloorIndicator

Wskaźnik piętra z parą strzałek — UI-owe echo strzałek z logo: niebieska w górę, bursztynowa w dół.

- Konsument podaje `value` (krótko: numer strony 01–05, numer kroku procesu), `label`, opcjonalnie `direction` (`up` / `down` / brak).
- Używaj jako akcentu: w hero (numer strony portfolio), w krokach procesu („01 Diagnose → 02 Repair → 03 Test”). Nie do prawdziwych statystyk.
- Najwyżej jeden zapalony wskaźnik w widoku.
