# SectionHeading

Nagłówek sekcji: tytuł i opcjonalny lead.

- Konsument podaje `title`, opcjonalnie `lead` (≤ 2 zdania), `level` (domyślnie h2), `align`.
- Nie stawiaj nad tytułem etykiety w wersalikach ani kreski-akcentu — tytuł otwiera sekcję sam.
- Każda sekcja strony zaczyna się od SectionHeading. `steel` tylko na ciemnym gruncie i tylko gdy rozmiar ≥ `h2`.
