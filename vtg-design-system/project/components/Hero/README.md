# Hero

Otwarcie strony: nagłówek display w stali, lead, akcje i portretowe zdjęcie z realizacji ze ściętym narożnikiem.

- Konsument podaje `title` (≤ 8 słów), `lead` (1–2 zdania), `actions` (maks. primary + secondary), `image` + `imageAlt` (zdjęcie z grupy Realizacje, najlepiej portret z szybu), opcjonalnie `aside`.
- Bez etykiety w wersalikach nad tytułem: hero zaczyna się od nagłówka.
- `size`: `display-xl` na stronie głównej, `display-l` na podstronach.
- W `aside` stawiaj `FloorIndicator` z numerem strony portfolio (01–05) — wiąże hero z systemem pięciu stron.
- Zawsze ciemny. Nie kładź tekstu na zdjęciu — kolumny obok siebie.
