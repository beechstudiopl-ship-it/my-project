# ServiceCard

Karta usługi lub specjalizacji z numerem, ikoną, listą podzespołów i linkiem.

- Konsument podaje `num` (numer strony portfolio 02–05 lub kolejność usługi 01…), `title`, opcjonalnie `subtitle`, `items` (3–4 podzespoły, rzeczowniki), `icon`, `href`, `linkLabel` (domyślnie „Learn more”).
- Na stronie grupy cztery karty linkują do czterech stron specjalistycznych — to główna nawigacja portfolio. Na stronach specjalistycznych karty opisują usługi danej strony.
- Siatka 3–4 kolumn, gap `space-6`. Wysokości wyrównuje grid; link zawsze na dole.
