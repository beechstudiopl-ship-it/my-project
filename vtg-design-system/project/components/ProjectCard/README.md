# ProjectCard

Karta realizacji: prawdziwe zdjęcie z prac, kategoria (specjalizacja), tytuł i lokalizacja.

- Konsument podaje `image` + `imageAlt` (z grupy Realizacje; alt opisuje technicznie, co widać), `title` (co zrobiono), `category` (nazwa specjalizacji), `location` (typ budynku · dzielnica), `href`.
- `tall` dla zdjęć portretowych — w siatce mieszaj jedną wysoką kartę z dwiema niskimi.
- Tytuły i lokalizacje w podglądzie to przykłady — zastąp prawdziwymi danymi z realizacji.
